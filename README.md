# Yan Qin's Academic Homepage

Personal academic homepage for [Yan Qin](https://yanqin2002.github.io/), built with Jekyll and adapted from [WowPage](https://github.com/WD7ang/WowPage).

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://127.0.0.1:4000/>.

Homepage content is maintained in `_pages/about.md`; profile metadata and social links are maintained in `_config.yml`.
